# 24주 확장 로드맵

| 기간 | 실행 | 평가 |
|---|---|---|
| 1–4주 | 낮은 세트·높은 RIR에서 시작해 동작과 일정을 적응 | 실제 완료율·통증·현재 수준 |
| 5–8주 | 같은 종목의 반복수를 축적하고 조건 충족 시 소폭 증량 | 최근 4주 실제 직접 세트·회복·기록 품질 |
| 9–12주 | 지속 가능한 주간 2/3/4회 선택 | 수행·체중 평균·허리둘레·이행률을 함께 확인 |
| 13–16주 | 핵심 동작 유지, 무리 없는 조절 | 16주에 빈도·시간·회복 재평가 |
| 17–20주 | 회복이 좋고 정체된 부위만 세트 1–2개 추가를 수동 검토 | 단일 변수 변경의 결과 확인 |
| 21–24주 | 지속 가능한 종목과 볼륨 정착 | 24주 점검 후 다음 블록 결정 |

특정 체중·근육량 증가를 보장하지 않습니다. 운동 CSV에는 근육량·체지방·섭취량·수면·통증 정보가 자동으로 들어 있지 않습니다. 사진은 원하는 사용자가 별도로 로컬 보관할 수 있지만 앱 사진 저장 기능은 구현하지 않았습니다.

체중 감소가 필요한지, 소폭 에너지 흑자가 필요한지, 유지에 가까운 체형 개선이 적합한지는 추가 측정과 목표에 따라 달라집니다. TDEE를 지어내지 않으며 2–4주 추세로 판단합니다. 급격한 보상 식사·보상 운동을 기본 규칙으로 두지 않습니다.
