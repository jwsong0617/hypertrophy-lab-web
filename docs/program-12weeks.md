# 12주 잠정 프로그램

이 문서는 일반적인 운영 구조입니다. 실제 기록·현재 수행·운동 허용 범위를 확인한 개인 확정 처방이 아닙니다. 앱은 민감한 개인 배경을 기본 번들에 포함하지 않습니다.

2026-10-23에 ACSM 2026 포지션 스탠드와 2024–2026 선택 고찰을 확인했습니다. 높은 볼륨의 평균적 이점을 보고하지만 초기부터 주 10세트를 의무화하지 않습니다. 직접·간접 집계 방식과 개인 회복의 차이를 고려하여 낮은 시작 볼륨과 단계적 증가를 유지합니다. 전신/분할은 2024 메타분석에서 볼륨을 맞추면 차이가 뚜렷하지 않아 이행률을 기준으로 선택합니다. 출처·확실성은 research-evidence.md와 research-verification.json에 연결됩니다.

## 빈도 선택

기본 주 3회 전신 A/B/C. 바쁜 주는 주 2회 전신 A/B. 선택 주 4회 상체/하체 A/B. 요일을 강제하지 않고 다음 슬롯으로 이어갑니다. 가능하면 같은 부위에 회복 시간을 두되 일정을 최우선으로 조정합니다. 주 4회가 더 우수하다는 전제는 없습니다.

## 3대·OHP 중심 선택

헬스장 환경에서 지지형 구성 대신 선택할 수 있으며 선택은 이 기기에 저장됩니다. 기구 운동이 자유중량보다 근비대에 우월하다는 전제를 두지 않습니다. 본인의 선호·기술·현재 허용 범위·회복으로 고릅니다. 기존 지지형 구성을 자동으로 바벨로 바꾸거나, 바벨 선택을 운동 허가로 간주하지 않습니다.

| 슬롯 | 핵심 동작 (5–7주 본세트 · 반복) | 보완 |
|---|---|---|
| A | 스쿼트 3×6–10, 벤치 3×6–10, 풀다운 3×8–12, 레그 컬 2×10–15 | 측면 어깨·코어 |
| B | 데드리프트 2×5–8, OHP 3×6–10, 지지형 로우 3×8–12, 스플릿 스쿼트 2×8–12 | 후면 어깨, 선택 카프 |
| C | 스쿼트 2×6–10, 벤치 3×6–10, 풀다운 3×8–12, 레그 컬 2×10–15 | 측면 어깨, 선택 힙 스러스트 |

바벨 복합 동작의 기본 휴식은 150초이며 회복이 부족하면 더 쉽니다. 1–2주에는 각 1세트/RIR 4, 3–4주는 최대 2세트/RIR 3으로 같은 단계 규칙을 적용합니다. 과거 최고중량·1RM 비율을 시작 부하로 지정하지 않습니다. 데드리프트는 근비대의 필수 동작이 아니며 원하지 않거나 불편하면 지지형 구성과 통증 없는 대안을 선택합니다. 벤치와 OHP는 전면 어깨·삼두의 간접 노출이 겹치므로 밀기 볼륨을 무조건 늘리지 않습니다.

주 2회 바벨 구성의 B는 데드리프트·벤치·로우·스플릿 스쿼트를 먼저, OHP·레그 컬을 뒤에 둡니다. 압축형에서도 두 날 모두 가슴·등·대퇴사두 노출을 유지하며 OHP는 생략될 수 있습니다. 주 4회는 상체 A에 벤치, 하체 A에 스쿼트, 상체 B에 OHP, 하체 B에 데드리프트를 먼저 배치합니다. 집 환경에서는 바벨 선호가 저장돼 있어도 집 대안을 사용합니다.

## 주 2회·4회

2회는 A와 B의 핵심 전신 동작을 사용하고 B의 마지막 두 동작은 측면 어깨와 코어로 구성합니다. 4회는 상체 A(체스트 프레스·로우·풀다운·측면 어깨·삼두·이두), 하체 A(레그 프레스·레그 컬·힙 스러스트·카프·코어), 상체 B(인클라인·풀다운·로우·후면/측면 어깨), 하체 B(스플릿 스쿼트·레그 컬·힙 스러스트·카프·코어)입니다. 정확한 주차별 표는 앱에서 빈도·시간·주차를 선택하면 생성됩니다. 원본 정의는 `src/domain/program.ts`입니다.

## 진행·회복·통증 규칙

1. 실제 수행한 세트만 기록하고 RIR는 선택 입력합니다. 공란은 자동 채우지 않습니다.
2. 최근 28일 안의 두 노출 모두 동일한 종목 표기, 같은 부하, 계획 본세트 수 이상, 반복 상단 이상, 목표 RIR 이상을 만족하고 오늘의 통증·피로·수면도 확인하면 약 2.5%를 기구 단위에 맞춰 제안합니다. 10%를 넘는 단위 점프는 제안하지 않습니다. 실제 적용은 사용자가 판단합니다.
3. 누락 RIR·반복 미달·세트 부족·미확인 부하는 유지합니다. 보조량과 맨몸에는 외부 중량 증량 공식을 적용하지 않습니다.
4. 통증 4 이상 또는 위험 증상은 운동 중단 안내. 가벼운 통증도 증량 보류. 피로 4/5 이상 또는 수면 5시간 미만은 세트 30–50% 축소를 권합니다. 이 임계값은 진단 기준이 아닌 보수적인 앱 운영 규칙입니다.
5. 3회 이상 정체하면 기술·기구 일관성·휴식·식사·수면·이행률부터 살핍니다. 자동으로 세트를 추가하지 않습니다.
6. 여러 세션에서 수행 저하·피로·통증이 이어지면 1주 세트 축소, RIR 증가, 동작 변경을 검토합니다. 예정된 평가 주차가 의학적 디로드를 대신하지 않습니다.

유산소는 운동 허용 범위를 확인한 경우 가벼운 걷기·자전거 등으로 시작하며 고강도 인터벌·최대중량 시험·긴 숨 참기를 기본으로 요구하지 않습니다.
